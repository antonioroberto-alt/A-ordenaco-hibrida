Projeto desenvolvido para a disciplina de Estruturas de Dados Avançadas do Professor Lucas.

Objetivo;
Implementar e comparar a quicksort pura com uma versão híbrida que utiliza ordenação por inserção em trechos pequenos.

- Quicksort com pivô aleatório.
- Particionamento em menores, iguais e maiores.
- Ordenação por inserção.
- Parâmetro `corte` configurável.
- Experimentos com 20.000 elementos aleatórios.
- Comparação de tempos de execução.
- Geração de tabela CSV e gráfico.

- Python 3
- Matplotlib

Instalação:

```bash
python -m pip install matplotlib
```

## Como executar

Executar os testes:

```bash
python testes.py
```

Executar os experimentos:

```bash
python experimento.py
```

Os resultados e a análise do desempenho estão documentados em `RELATORIO.md`.
